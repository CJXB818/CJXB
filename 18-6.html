图一：智能客服问答业务流程图

flowchart

从用户发起咨询到答案返回的完整链路，包含意图识别、RAG 知识检索、置信度判定、人工兜底与标注回流。

flowchart TD
    A([用户发起咨询]) --> B{接入渠道}
    B -->|网页 / App| C[消息网关]
    B -->|电话语音| D[ASR 语音转文本]
    D --> C
    C --> E[文本预处理]
    E --> F[意图识别 NLU]

    F --> G{是否知识问答}
    G -->|否| H[转人工坐席]
    G -->|是| I[知识库检索 RAG]

    I --> J{召回置信度达标}
    J -->|否| K[澄清追问]
    K --> F
    J -->|是| L[大模型生成答案]

    L --> M[事实校验与引用溯源]
    M --> N{审核通过}
    N -->|否| H
    N -->|是| O[返回用户]

    O --> P[满意度评价]
    P --> Q[日志入湖与样本标注]
    Q --> I

    H --> R([人工处理完成])

图二：智能客服系统 ER 图

erDiagram

描述会话、消息、答案、知识库与工单之间的实体关系，其中知识条目经切分与向量化后供 RAG 检索使用。

erDiagram
    USER ||--o{ SESSION : "发起"
    SESSION ||--o{ MESSAGE : "包含"
    MESSAGE ||--o| ANSWER : "生成"
    ANSWER }o--o{ KNOWLEDGE : "引用"
    KNOWLEDGE ||--o{ CHUNK : "切分"
    CHUNK ||--o{ VECTOR : "向量化"
    SESSION ||--o| TICKET : "转人工"
    AGENT ||--o{ TICKET : "处理"
    ANSWER ||--o{ FEEDBACK : "评价"

    USER {
        bigint id PK "用户主键"
        varchar nickname "昵称"
        varchar channel "来源渠道"
        datetime created_at "创建时间"
    }
    SESSION {
        bigint id PK "会话主键"
        bigint user_id FK "所属用户"
        varchar status "进行中 / 已结束"
        datetime started_at "开始时间"
    }
    MESSAGE {
        bigint id PK "消息主键"
        bigint session_id FK "所属会话"
        varchar role "user / bot"
        text content "消息内容"
    }
    ANSWER {
        bigint id PK "答案主键"
        bigint message_id FK "对应消息"
        decimal confidence "置信度"
        varchar status "通过 / 转人工"
        text citations "引用条目"
    }
    KNOWLEDGE {
        bigint id PK "知识条目"
        varchar title "标题"
        varchar category "分类"
        varchar version "版本号"
    }
    CHUNK {
        bigint id PK "切分段"
        bigint knowledge_id FK "所属条目"
        int seq "段序号"
        text content "文本内容"
    }
    VECTOR {
        bigint id PK "向量主键"
        bigint chunk_id FK "所属切分段"
        varchar model "Embedding 模型"
        blob embedding "向量数据"
    }
    TICKET {
        bigint id PK "工单主键"
        bigint session_id FK "来源会话"
        bigint agent_id FK "处理坐席"
        varchar priority "优先级"
        varchar state "待处理 / 已解决"
    }
    AGENT {
        bigint id PK "坐席主键"
        varchar name "姓名"
        varchar group_name "技能组"
        int online "在线状态"
    }
    FEEDBACK {
        bigint id PK "评价主键"
        bigint answer_id FK "对应答案"
        int score "1-5 分"
        varchar comment "评价内容"
    }
