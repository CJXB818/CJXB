# HTML Practice Skill

This skill helps create educational HTML/CSS/JS practice exercises.

## When to Invoke

Invoke this skill when:
- User asks to create HTML practice pages
- User wants CSS layout exercises
- User needs interactive JavaScript demo pages
- User mentions specific rules or patterns to implement (e.g., number games, grid layouts)

## Guidelines

1. Always include a clear title with the student's name
2. Use external or internal CSS with clean, readable styles
3. Prefer vanilla JavaScript without frameworks for learning
4. Add comments explaining key concepts
5. Make the page visually appealing with proper spacing and colors

## Example Exercises

- 逢七过 game (multiples of 7 and numbers containing 7)
- CSS selector priority demo
- Form validation practice
- Flexbox/Grid layout exercises
