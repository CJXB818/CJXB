JavaScript 程序结构

徐奔 · 顺序结构 · 条件结构 · 循环结构

一、顺序结构

顺序结构是最简单的程序结构，从上到下一条条依次执行。就像读课文一样。
// 计算圆的面积（顺序执行） let r = 5; let pi = 3.14159; let area = pi * r * r; let perimeter = 2 * pi * r; console.log("半径:" + r); console.log("面积:" + area); console.log("周长:" + perimeter);

二、条件结构

条件结构根据条件判断，选择不同的分支执行。if / else if / else 或 switch。

2.1 if-else 判断成绩等级

let score = 85; if (score >= 90) { console.log("优秀 A"); } else if (score >= 80) { console.log("良好 B"); } else if (score >= 60) { console.log("及格 C"); } else { console.log("不及格 D"); }
点击按钮看结果...

2.2 switch 判断星期

let day = 3; switch (day) { case 1: console.log("星期一"); break; case 2: console.log("星期二"); break; case 3: console.log("星期三"); break; default: console.log("其他"); }

三、循环结构

循环结构让一段代码重复执行。for、while、do-while 三种常用循环。

3.1 for 循环 —— 输出 1~10

for (let i = 1; i <= 10; i++) { console.log(i); }
点击按钮看结果...

3.2 while 循环 —— 计算 1~100 累加和

let sum = 0; let n = 1; while (n <= 100) { sum += n; n++; } console.log("1+2+...+100 =" + sum); // 结果: 5050
点击按钮看结果...

3.3 循环 + 条件 —— 逢七过（1~30）

for (let i = 1; i <= 30; i++) { if (i % 7 === 0 || String(i).indexOf("7") !== -1) { console.log("跳过"); } else { console.log(i); } }
