一、JSON 是“字符串”，不是对象

JSON（JavaScript Object Notation）是一种文本格式，长得像 JS 对象，但它本质是字符串。 服务器和浏览器之间传输数据时用它，因为文本任何语言都认识。
左边是 JS 对象（内存里的东西），右边是 JSON 字符串（可以发给服务器的文本）。 JSON.stringify() 把对象变成字符串，JSON.parse() 把字符串变回对象。

二、JSON 的六条硬规则

JSON 比 JS 对象字面量严格得多，写错一个引号就解析失败。下面是和 JS 写法的对比。
规则 JS 对象写法 JSON 写法
键名必须双引号 { name: '小明' } { "name": "小明" }
字符串必须双引号 { "name": '小明' } { "name": "小明" }
不能有函数 { "fn": function(){} } 去掉函数，只传数据
不能有 undefined { "a": undefined } { "a": null }
不能有注释 { /* 注释 */ "a": 1 } { "a": 1 }
不能有尾逗号 { "a": 1, } { "a": 1 }
const obj = { name: '小明', age: 18 }; const str = JSON.stringify(obj); // '{"name":"小明","age":18}' const back = JSON.parse(str); // 又变回对象 // stringify 的三个常用参数：值、替换器、缩进 JSON.stringify(obj, null, 2); // 缩进 2 空格，适合展示 JSON.stringify(obj, ['name']); // 只要 name 字段 → '{"name":"小明"}' // 判断字符串能不能转：用 try...catch try { JSON.parse('{name:"小明"}'); // 键没加引号，报错 } catch (e) { console.log(e.message); }
