fetch 获取接口数据

徐奔 · 请求 → 解析 → 渲染 · 加载中 / 成功 / 失败

一、fetch 的固定套路

fetch() 返回一个 Promise，它只负责“把请求发出去”，不会因为 404、500 而进 catch， 所以要先判断 res.ok；再用 res.json() 把响应体解析成对象（这一步也是异步的，要再 await 一次）。 真正的网络错误（断网、跨域被拦）才会进入 catch。
const url = 'https://dummyjson.com/products?limit=8'; async function loadData() { try { const res = await fetch(url); // ① 发请求 if (!res.ok) { // ② 检查状态码 throw new Error('HTTP ' + res.status); } const data = await res.json(); // ③ 解析成对象 render(data.products); // ④ 渲染到页面 } catch (err) { showError(err.message); // ⑤ 出错提示 } }
