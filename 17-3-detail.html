徐奔 · 根据 URL 中的 id 请求单个商品

详情页：先取 id，再发请求

列表页跳转过来时带上了 ?id=1，详情页用 URLSearchParams 从地址栏里把 id 读出来， 拼成 https://dummyjson.com/products/1 再请求。 如果地址里没有 id、或者 id 对应的商品不存在，需要给出明确的提示，而不是白屏。
const params = new URLSearchParams(location.search); const id = params.get('id'); if (!id) { showError('地址里缺少 id 参数'); return; } const res = await fetch('https://dummyjson.com/products/' + id); // 商品不存在时接口返回 404，res.ok 为 false if (!res.ok) throw new Error('HTTP ' + res.status); const p = await res.json();
‹ 返回商品列表
