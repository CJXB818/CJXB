用 Promise / async 包一顿饺子

徐奔 · Promise.race 抢一个 · Promise.all 等全部 · async/await 串流程

一、流程里有两个“并发”

① 买原料：线上线下同时下单，谁先到就用谁的 —— 用 Promise.race()， 多个 Promise 里最快完成的那一个决定结果，其余的不用再等。
② 和面、和馅：两边都得做完才能包 —— 用 Promise.all()， 要全部完成才继续，任何一个失败则整体失败。
其余步骤（取原料 → 包饺子 → 煮饺子 → 吃饺子）都是排队执行，用 await 一行行写。

Promise.all —— 等全部

和面 4 秒、和馅 3 秒同时开始，两个都完成才轮到包饺子。
缺一个都不行，所以用 all。

Promise.race —— 抢第一

线上买 6 秒、线下买 4 秒同时开始，谁先完成就用谁，
另一个自动作废，所以用 race。

// 用 setTimeout 把“等待”封装成 Promise function delay(name, ms) { return new Promise((resolve) => { setTimeout(() => resolve(name), ms); }); } async function cook() { // ① 抢：线上线下谁快用谁 const buyer = await Promise.race([ delay('线上购买', 6000), delay('线下购买', 4000) ]); await delay('取原料', 2000); // ② 等：和面、和馅都要做完 await Promise.all([ delay('和面', 4000), delay('和馅', 3000) ]); await delay('包饺子', 3000); await delay('煮饺子', 5000); await delay('吃饺子', 1000); }

三、同一件事的两种写法

// async / await：像写同步代码一样写异步，最易读 async function cook() { const buyer = await Promise.race([ delay('线上购买', 6000), delay('线下购买', 4000) ]); log('用' + buyer + '买到了原料'); await delay('取原料', 2000); await Promise.all([ delay('和面', 4000), delay('和馅', 3000) ]); await delay('包饺子', 3000); await delay('煮饺子', 5000); await delay('吃饺子', 1000); }
// Promise 链：每一步 return 一个 Promise，交给下一个 then Promise.race([ delay('线上购买', 6000), delay('线下购买', 4000) ]) .then((buyer) => { log('用' + buyer + '买到了原料'); return delay('取原料', 2000); }) .then(() => Promise.all([ delay('和面', 4000), delay('和馅', 3000) ])) .then(() => delay('包饺子', 3000)) .then(() => delay('煮饺子', 5000)) .then(() => delay('吃饺子', 1000)) .then(() => log('全部完成')) .catch((err) => log('出错了：' + err)) .finally(() => log('收尾'));

注意 race 的一个特点：它只取最快的那一个结果，不会取消其他 Promise， 输掉的那个计时器仍在后台走完，只是我们不再关心它 —— 页面里那个变灰的分支就是这个意思。
要不要用 all 还是 race，取决于业务：“两个都得完成”用 all，“有一个就行”用 race。
