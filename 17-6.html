用 Promise / async 包一顿饺子

徐奔 · 串行 → 并行 → 汇总 · 用 setTimeout 模拟每一步耗时

一、先理清流程

买原料（6 秒）→ 取原料（2 秒）→ 和面（4 秒）与和馅（3 秒）同时进行 → 两样都完成才能包饺子（3 秒）→ 吃饺子（1 秒）。
串行执行总共需要 6+2+4+3+3+1 = 19 秒； 因为和面、和馅可以并行，实际只需 16 秒。页面上的进度条会如实反映这一点。
// 把“等待”封装成 Promise，用时用 setTimeout 模拟 function delay(name, ms) { return new Promise((resolve) => { setTimeout(() => { console.log(name + ' 完成'); resolve(name); // 到点后把 Promise 标记为成功 }, ms); }); } async function cook() { await delay('买原料', 6000); await delay('取原料', 2000); // Promise.all：两个同时开始，都完成才继续 await Promise.all([ delay('和面', 4000), delay('和馅', 3000) ]); await delay('包饺子', 3000); await delay('吃饺子', 1000); console.log('全部完成'); }

三、同一件事的两种写法

// async / await：像写同步代码一样写异步，最易读 async function cook() { await delay('买原料', 6000); await delay('取原料', 2000); await Promise.all([ delay('和面', 4000), delay('和馅', 3000) ]); await delay('包饺子', 3000); await delay('吃饺子', 1000); }
// Promise 链式调用：每一步 return 出去，交给下一个 then delay('买原料', 6000) .then(() => delay('取原料', 2000)) .then(() => Promise.all([ delay('和面', 4000), delay('和馅', 3000) ])) .then(() => delay('包饺子', 3000)) .then(() => delay('吃饺子', 1000)) .then(() => console.log('全部完成')) .catch((err) => console.log('出错了：' + err)) .finally(() => console.log('收尾'));

顺序执行：一个 await 接一个，前一步做完才走下一步。
并行执行：先让两个 Promise 都“跑起来”，再用 Promise.all 一起等； 写成 await a; await b; 就变成串行了，多花 3 秒。
共同点：两种写法本质是同一条 Promise 链，async/await 只是让代码读起来像同步。
