零、先分清两类方法

数组方法最重要的一个区别：调用后原数组会不会被改变。下面用方块图把数组“画”出来，点按钮就能看到元素怎么变。
会改原数组：push pop unshift shift sort reverse splice 不改原数组：map filter slice concat join forEach reduce find indexOf

图例：■ 绿色 = 新加入　■ 红色 = 被删除　■ 黄色 = 被访问 / 被选中

一、增删方法（直接修改原数组）

push 尾部添加、pop 尾部删除、unshift 头部添加、shift 头部删除。 它们都会原地修改数组，并且有返回值：push / unshift 返回新长度，pop / shift 返回被删掉的元素。
// 初始数组 let fruits = ['🍎', '🍌', '🍇']; fruits.push('🍉'); // 末尾加一个，返回 4（新长度） fruits.pop(); // 末尾删一个，返回 '🍉' fruits.unshift('🍓'); // 头部加一个，返回 4 fruits.shift(); // 头部删一个，返回 '🍓'

二、遍历与变形：forEach / map / filter / reduce

这一组方法都要传一个回调函数，数组会自己把每个元素挨个交给它。
forEach 只遍历不返回；map 一一映射成新数组；filter 按条件筛选；reduce 把所有元素“揉”成一个值。
const nums = [1, 2, 3, 4, 5, 6]; nums.forEach(n => console.log(n * n)); // 只做事，返回值是 undefined nums.map(n => n * 2); // [2, 4, 6, 8, 10, 12] 一一对应 nums.filter(n => n % 2 === 0); // [2, 4, 6] 留下满足条件的 nums.reduce((acc, n) => acc + n, 0); // 21 累积成一个值

三、查找与判断：includes / indexOf / find / some / every

includes 有没有、indexOf 在第几个、find 找出第一个满足条件的元素、some 是否至少有一个满足、every 是否全部都满足。
const arr = ['苹果', '香蕉', '葡萄', '西瓜', '柠檬', '火龙果']; arr.includes('葡萄'); // true 有没有这个元素 arr.indexOf('葡萄'); // 2 找不到返回 -1 arr.find(x => x.length > 2); // '火龙果' 返回元素本身 arr.findIndex(x => x.length > 2); // 5 返回下标 arr.some(x => x.length > 2); // true 只要有一个满足就是 true arr.every(x => x.length >= 2); // true 必须全部满足才是 true

四、排序、截取与拼接：sort / reverse / slice / splice / concat / join

这里最容易混的是 slice 和 splice：
slice(开始, 结束) 是“切一份出来”，原数组不动；splice(开始, 个数, 新元素...) 是“动刀改原数组”，可以删、可以换、可以插。
const nums = [10, 9, 100, 1, 25]; nums.sort(); // [1, 10, 100, 25, 9] ⚠ 默认按字符串排！ nums.sort((a, b) => a - b); // [1, 9, 10, 25, 100] 数字排序必须给比较函数 nums.reverse(); // 整个数组倒过来 const letters = ['A', 'B', 'C', 'D', 'E']; letters.slice(1, 3); // ['B','C'] 原数组不变 letters.splice(1, 2, 'X', 'Y'); // ['A','X','Y','D','E'] 原数组被改 letters.concat(['F', 'G']); // 拼接成新数组 letters.join('-'); // "A-B-C-D-E" 变成字符串

五、综合实战：一次处理学生成绩

真实开发中，这些方法几乎总是链式组合使用：filter 筛选 → sort 排序 → map 提取 → reduce 汇总。
const students = [ { name: '小明', score: 92 }, { name: '小红', score: 78 }, { name: '小刚', score: 58 }, { name: '小美', score: 88 }, { name: '小强', score: 66 } ]; // 1. 只要及格的 const pass = students.filter(s => s.score >= 60); // 2. 按分数从高到低 const sorted = [...students].sort((a, b) => b.score - a.score); // 3. 提取成 “姓名:分数” 的字符串 const names = pass.map(s => s.name + ':' + s.score); // 4. 汇总平均分 const avg = students.reduce((sum, s) => sum + s.score, 0) / students.length;
