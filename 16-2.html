JavaScript 对象与字符串图解

一、对象：把一堆数据装进一张“名片”

对象是键值对（key: value）的集合。数组用数字下标找元素，对象用名字找值。 下面每一行就是一条属性：紫色是键，右边是值。
let student = { name: '小明', age: 18, isStudent: true };
点击按钮，观察对象里属性的增加、修改与删除。

二、访问属性：点号 与 方括号

obj.name 写法简单，用于固定的属性名；obj['name'] 方括号里可以放变量， 也能访问带空格、带横线的属性名。
const user = { name: '小明', age: 18, 'my-score': 95 // 带横线，只能用方括号访问 }; user.name // '小明' user['name'] // '小明' const key = 'age'; user[key] // 18 方括号里放变量 user['my-score'] // 95 只能用方括号

三、对象里的函数：方法 与 this

当属性的值是一个函数时，它就叫做对象的方法。方法里的 this 指向“调用它的那个对象”， 所以 this.name 能拿到同一个对象里的 name。
const person = { name: '小明', age: 18, intro() { return '我叫' + this.name + '，今年' + this.age + '岁'; } }; person.intro(); // '我叫小明，今年18岁'
点击按钮运行方法。

四、遍历对象：keys / values / entries / for-in

对象没有 length，也不能用普通 for 循环遍历。 Object.keys() 拿所有键，Object.values() 拿所有值，Object.entries() 拿 [键, 值] 数组， for...in 直接循环键名。
const book = { title: '三体', author: '刘慈欣', price: 39 }; Object.keys(book); // ['title','author','price'] Object.values(book); // ['三体','刘慈欣',39] Object.entries(book); // [['title','三体'], ...] for (let k in book) { console.log(k + ' = ' + book[k]); }

五、字符串：一串“定格”的字符

字符串可以像数组一样用下标取字符，也有 length。 但注意：字符串不可变，任何方法都只是生成一个新字符串，原来的不会被改。
const str = 'Hello'; str.length // 5 str[0] // 'H' 下标从 0 开始 str[4] // 'o' str[10] // undefined 越界不会报错 // 想改一个字符？只能重新生成一个字符串 str[0] = 'J'; // ✗ 无效，不会报错但也没效果 const newStr = 'J' + str.slice(1); // ✓ 'Jello'
str = 'Hello' —— 每个方块是一个字符，下面是下标
点击按钮，看字符串的每一个字符。

字符串方法速查表

方法作用示例
length长度（属性，不加括号）'abc'.length → 3
toUpperCase()全部转大写'ab'.toUpperCase() → 'AB'
trim()去掉首尾空格' a '.trim() → 'a'
slice(a, b)截取 [a, b) 区间，不改原串'hello'.slice(1,3) → 'el'
indexOf(x)找位置，找不到返回 -1'hello'.indexOf('l') → 2
includes(x)是否包含，返回布尔值'hello'.includes('ell') → true
startsWith / endsWith是否以…开头 / 结尾'hello'.startsWith('he') → true
replace(a, b)替换（默认只换第一个）'aaa'.replace('a','b') → 'baa'
replaceAll(a, b)替换全部'aaa'.replaceAll('a','b') → 'bbb'
split(x)按分隔符切成数组'a,b'.split(',') → ['a','b']
repeat(n)重复 n 次'ab'.repeat(2) → 'abab'
padStart(n, c)前面补字符到 n 位'7'.padStart(3,'0') → '007'

注意：以上方法都不会改变原字符串，必须用变量接收返回值：let s2 = s.trim();

七、模板字符串：用反引号拼字符串

用 `（反引号）包裹，${} 里可以直接写变量或表达式，还能直接换行。比用 + 号拼接清爽得多。
const name = '小明'; const age = 18; // 旧写法：一堆加号和引号 '我叫' + name + '，明年' + (age + 1) + '岁'; // 模板字符串：想写什么写什么

八、综合实战：用对象 + 模板字符串生成名片

对象负责存数据，模板字符串负责把数据“排版”成 HTML，这就是前端最基础的渲染方式。
const me = { name: '徐奔', city: '南京', skills: ['HTML', 'CSS', 'JavaScript'], tags() { return this.skills.map(s => s).join(' / '); } };
