一、请求是怎么拼出来的

fetch(url, options) 的第二个参数决定“怎么请求”：method 是请求方法， headers 说明发的是 JSON，body 放要提交的数据。 GET 不允许带 body（浏览器会直接报错），POST / PUT / PATCH 才需要 body。
const options = { method: 'POST', headers: { 'Content-Type': 'application/json' }, body: JSON.stringify({ title: 'foo', body: 'bar', userId: 1 }) }; const res = await fetch('https://jsonplaceholder.typicode.com/posts', options); const data = await res.json(); // res.status 是状态码：200 成功、201 创建成功、404 找不到、500 服务器错误
